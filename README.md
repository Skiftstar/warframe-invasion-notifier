# What is this?

This tool uses [warframestat](https://docs.warframestat.us/) to display all currently ongoing Invasions. It provides the options for you to set-up notifiers for when a specific Item is currently available.

To access the page [go here](https://skiftstar.github.io/warframe-invasion-notifier/)

# Attention

Please make sure Notifications are enabled for the webpage! The tab with the page needs to stay active!
